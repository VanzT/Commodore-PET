ICBM GAME - VARIABLE REFERENCE
================================================================================
All variables are 2 characters max (PET BASIC limitation)
Last updated: 2026-01-14 (Phase 2 - Multi-site ABM System)

================================================================================
ARRAYS
================================================================================
M$(100,8)  Missile data array (100 missiles max)
           Field 0: Hex location (e.g., "1007")
           Field 1: Type code (1-9, see MISSILE TYPE CODES below)
           Field 2: Duration remaining (turns in flight)
           Field 3: Movement points per turn
           Field 4: Strength (damage to cities)
           Field 5: Owner ("1"=USA, "2"=USSR)
           Field 6: Status ("0"=inactive, "1"=active, "8"=impacted, "9"=destroyed)
           Field 7: Target hex (where missile is headed)
           Field 8: ABM sites fired (list of site indices that fired at this missile this hex)
                    Format: "1:3:5:" means sites 1, 3, and 5 have fired
                    Cleared when missile moves to new hex (line 9676)
                    Prevents same site from firing twice at same hex

A$(15,4)   ABM site data array (15 sites max)
           Field 0: Hex location
           Field 1: Owner ("1"=USA, "2"=USSR)
           Field 2: Rounds remaining
           Field 3: Site designation letter (A-F)

C$(50,3)   City data array (50 cities max)
           Field 0: Hex location
           Field 1: Point value remaining
           Field 2: Owner ("1"=USA, "2"=USSR)
           Field 3: TARGET COUNTER ENCODING (ones=ABM count, tens=missiles targeting)
                    Example: "23" = 3 ABMs nearby, 2 missiles targeting
                    Recalculated each USSR turn for targeting optimization

B$(30,2)   Base data array (30 bases max)
           Field 0: Hex location
           Field 1: Owner ("1"=USA, "2"=USSR)

MISSILE TYPE CODES (Numeric Encoding)
================================================================================
Due to PET BASIC 2-char variable limit, missile types use numeric codes:

USSR Missiles:
  1 = SS18  (Duration:4, Move:10, Strength:8)
  2 = SS9   (Duration:4, Move:10, Strength:6)
  3 = SS19  (Duration:4, Move:8,  Strength:5)
  4 = SS17  (Duration:4, Move:8,  Strength:3)
  5 = SS11  (Duration:4, Move:8,  Strength:2)
  6 = SS13  (Duration:4, Move:6,  Strength:1)

USA Missiles:
  7 = M2    (Minuteman II,  Duration:4, Move:9, Strength:3)
  8 = M3    (Minuteman III, Duration:4, Move:9, Strength:6)
  9 = TT    (Titan II,      Duration:4, Move:9, Strength:7)

Display conversion: GOSUB 19000 sets MT$ to display name

NOTES
================================================================================
- All hex coordinates are 4-digit strings: "XXYY" where XX=column, YY=row
- Owner field: "1"=USA, "2"=USSR (stored as strings in arrays)
- Status codes: "0"=inactive, "1"=active, "8"=impacted, "9"=destroyed
- PET BASIC only uses first 2 characters of variable names
- String variables end with $ (e.g., TG$ = target hex)
- Numeric variables have no suffix (e.g., TU = turn number)

SAVE/LOAD SYSTEM
================================================================================
Files created on device 8 (disk):
  ICBM-HEAD     - Turn, scores, counters (TU, UP, SP, F1, MC, AC, CC, BC)
  ICBM-BASES    - Base hex, owner, then 9 missile type counts (S1-S6, M7-M9)
  ICBM-ABM      - ABM hex, owner, rounds, designation letter
  ICBM-ACTIVE   - Active missile data (hex, type code, duration, move, str, owner, target)
  ICBM-CITIES   - City hex, value, owner

Channel Usage:
  Channel 1: ICBM-HEAD, ICBM-BASES, ICBM-ABM, ICBM-CITIES
  Channel 2: ICBM-ACTIVE

Menu options:
  Main menu: (N)ew Game, (L)oad Saved Game
  After USA turn: (E)nd Turn, (S)ave Game

Game State Display After Load:
  1. Shows all bases with USA/USSR owner
  2. Pauses every 20 lines if needed, then prompts to continue
  3. Clears screen and shows all ABM sites with USA/USSR owner
  4. Pauses every 20 lines if needed, then prompts to continue
  5. Clears screen and shows all active missiles with USA/USSR owner
  6. Pauses every 20 lines if needed, then prompts to continue
  7. Clears screen and resumes game

CRITICAL FIXES IMPLEMENTED:
  - Missile type codes are numeric (1-9) not text - avoids BASIC 2-char limit
  - Base owner stored as "1" or "2", not missile count
  - FOR loops use IF checks to prevent execution when count=0
  - Different loop variables (J1-J9) for each missile type
  - EOF(2) not reliable - use MC counter instead
  - Separate channels for each file to avoid open/close issues
  - K$ cleared before each GET to prevent infinite loops

PHASE 2 - MULTI-SITE ABM SYSTEM:
  - M$(I,8) cleared at start of each missile movement (line 9676)
  - M$(I,8) stores list of site indices that fired this hex (e.g., "1:3:5:")
  - USA ABM prompt (10505-10597):
    * Prompts for rounds from all sites in range
    * Stores choices in R1-R9 variables
    * Deducts ALL rounds immediately (before rolling)
    * Adds fired sites to M$(I,8) to prevent re-firing same hex
    * Rolls for all rounds until missile hit or all rounds exhausted
  - Same site CAN fire at same missile in different hexes
  - Site CANNOT fire twice at same missile in same hex

GOSUB 19000: Converts M$(I,1) numeric code to display name in MT$
